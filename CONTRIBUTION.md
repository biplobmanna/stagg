
# Contributing to Stagg 🤝✨

Thank you for your interest in contributing to Stagg! We welcome all kinds of contributions—code, documentation, bug reports, feature requests, and ideas. This guide will help you get started and ensure a smooth collaboration. 🙌

## 🚦 How to Contribute

1. 🍴 **Fork the Repository**
   - Click the "Fork" button at the top right of the repo page.

2. 🧑‍💻 **Clone Your Fork**
   - `git clone https://github.com/<your-username>/stagg.git`
   - `cd stagg`

3. 🌱 **Create a Branch**
   - `git checkout -b feature/your-feature-name`
   - Use descriptive branch names (e.g., `fix/typo-in-readme`, `feature/async-rendering`).

4. ✍️ **Make Your Changes**
   - Write clear, concise code and comments.
   - Follow Go best practices and keep dependencies limited to the standard library.

5. 🧪 **Test Your Changes**
   - Ensure your code builds and runs as expected.
   - Add or update tests if relevant.

6. 📤 **Commit and Push**
   - `git add .`
   - `git commit -m "Describe your changes"`
   - `git push origin feature/your-feature-name`

7. 🔀 **Open a Pull Request**
   - Go to your fork on GitHub and click "New Pull Request".
   - Fill in a clear title and description.
   - Reference any related issues if applicable.

## 🌟 Guidelines

- 🤝 Be respectful and collaborative.
- 🧹 Keep code readable and maintainable.
- 📝 Document new features and changes.
- 🎯 Prefer small, focused pull requests.
- 💡 All ideas and suggestions are welcome!
- 😄 No need to be perfect—just do your best.

## 🧑‍⚖️ Code of Conduct

We expect all contributors to be welcoming and respectful. Harassment or discrimination of any kind will not be tolerated. 🌈
